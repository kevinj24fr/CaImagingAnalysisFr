What this is (and isn’t)

A single entry point for calcium imaging workflows. It’s built around a CaExperiment container to standardize traces, metadata, results, and provenance.

  • Inputs: traces (cells × time), frame rate, metadata
  • Outputs: dF/F, spikes/events, latent embeddings, graphs, plots
  • Goal: consistent pipelines + clean accessors

Quick Start

Minimal pipeline example. Keep this aligned with your exported API (don’t advertise functions that aren’t stable/exported). 

library(CaImagingAnalysisFr)

# Create CaExperiment and run a typical pipeline
ca <- CaExperiment(traces, frame_rate = 30) |>
  RunDFF(method = "rolling", window_size = 300) |>
  RunSpikes(method = "threshold", threshold_sd = 2.5) |>
  RunPCA(n_components = 15) |>
  RunConnectivity(method = "correlation") |>
  RunGraphMetrics()

# Access results
dff_traces <- GetTraces(ca, assay = "dff")
spikes     <- GetSpikes(ca)
pca        <- GetReduction(ca, "pca")
conn       <- GetGraph(ca, "connectivity_correlation")

Core Capabilities

The package is organized around a common object model and composable “Run*()” steps with explicit accessors.

CaExperiment Object

Unified Seurat-style container for traces, metadata, results, and command/provenance tracking.

Preprocessing

Typical steps: neuropil subtraction, dF/F, event/spike inference (method-dependent), QC, and normalization.

Dimensionality Reduction

Common reductions (e.g., PCA/GPFA-style embeddings) for population trajectories and state structure.

Network Analysis

Functional connectivity estimates, graph metrics, community detection, and network visualization.

State Space Models

State segmentation via HMM / switching models, plus changepoint-style methods (where implemented).

Advanced Methods

TDA / recurrence-style summaries / optimal transport-style comparisons (where implemented and documented).
