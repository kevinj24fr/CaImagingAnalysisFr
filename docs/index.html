Calcium imaging analysis in R, end-to-end.

CaImagingAnalysisFr is a structured R toolkit for calcium imaging pipelines: traces → preprocessing → event/spike inference → latent structure → connectivity → figures.

Seurat-style object API Provenance / commands Models + networks + plots Designed for real pipelines

No framework. No heavy JS. One page that loads fast and looks like a real product.

What you get

One container (CaExperiment) that keeps data + results + metadata consistent across steps.

  • Inputs: traces (cells × time), frame rate, metadata
  • Outputs: dF/F, events/spikes, embeddings, graphs, plots
  • Pattern: Run* methods + Get* accessors

If a function isn’t exported/stable yet, don’t advertise it. This page stays clean and defensible.

Quick start
Minimal pipeline. Keep this aligned with your actual exported API.
library(CaImagingAnalysisFr)

ca <- CaExperiment(traces, frame_rate = 30) |>
  RunDFF(method = "rolling", window_size = 300) |>
  RunSpikes(method = "threshold", threshold_sd = 2.5) |>
  RunPCA(n_components = 15) |>
  RunConnectivity(method = "correlation") |>
  RunGraphMetrics()

dff   <- GetTraces(ca, assay = "dff")
spk   <- GetSpikes(ca)
pca   <- GetReduction(ca, "pca")
graph <- GetGraph(ca, "connectivity_correlation")
Scope
Structured workflow coverage. You can tighten/expand this list without changing the layout.

Preprocessing

Standardization steps: baseline / dF/F, denoising, event/spike inference, QC summaries.

RunDFF() RunSpikes() RunTransients()

Latent structure

Embeddings and low-dimensional trajectories for population dynamics and state structure.

RunPCA() RunGPFA() RunTensorDecomp()

Networks

Functional connectivity estimates, graph metrics, modular structure, visualization helpers.

RunConnectivity() RunGraphMetrics() plot_connectivity_matrix()

State-space / segmentation

State inference and regime changes via discrete/continuous switching models (where implemented).

RunHMM() RunSLDS() RunChangepoints()
API shape
This is the only “contract” users care about: predictable verbs and stable accessors.

Run* methods

Composable, pipeline-friendly steps that add results back into the object.

RunDFF() RunSpikes() RunPCA() RunConnectivity() RunGraphMetrics()

Get* accessors

Stable, explicit access to results without slot spelunking.

GetTraces() GetSpikes() GetReduction() GetGraph() GetCommands()
